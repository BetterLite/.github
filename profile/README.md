**We are BetterLite** — a small team of developers who started out running a public Minecraft server and publishing our own plugins. Over time we grew, learned, and changed direction: today we maintain PocketMine-MP and we are building **BetterLite**, our own next-generation PHP server software for Minecraft: Bedrock Edition.

---

## 👥 The Team

We are a passionate group of developers, server admins, and plugin authors who love Minecraft and the open-source ecosystem around it.

Our story:
- 🎮 **Where it started** — running a public Minecraft server, sharing our custom plugins with the community
- 🔧 **Where we are now** — maintaining PocketMine-MP, fixing bugs, keeping it up to date
- 🚀 **Where we're going** — building **BetterLite**, a brand-new PHP server software with a Bukkit-Like API

---

## 🛠️ What We Do

### 1. PocketMine-MP Fork
We maintain a fork of [PocketMine-MP](https://github.com/pmmp/PocketMine-MP) focused on:
- 🐛 **Bug fixes** — tracking, triaging and resolving issues faster than upstream
- 📦 **Up-to-date support** for the latest Minecraft: Bedrock Edition versions
- ✅ **Backward compatibility** — existing plugins keep working
